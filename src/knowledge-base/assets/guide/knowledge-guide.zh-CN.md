# 开始使用 EchoInk 知识库

EchoInk 会把当前 Vault 整理成一套由你自己保管的知识库。默认初始化先建立十个目录，再把体系外的普通文件原样移入 `raw/imported/原来的相对路径`。Markdown 笔记可以交给 AI 提炼；图片、PDF 和其他附件只负责归档，不会被当成文字强行处理。

已有知识目录里的文件保持原位。初始化保留原文和已有同名文件；冲突项会跳过并说明，其他独立项目继续处理。目录改名时，Obsidian 会按设置更新链接以保持引用有效。

## 日常怎么整理知识

平时不需要先把每篇笔记分得很细。把新资料放进 `raw/`，或先收进 `inbox/`，再按下面的顺序使用即可。

1. **保留原始资料。** Raw 是资料源。原文、附件和原来的目录关系都可以留在这里，方便随时回看。
2. **用 `/maintain` 整理。** 在 EchoInk 对话里输入 `/maintain`，让 Agent 分析待处理的 Markdown。只读时提供整理建议；工作区可写且你要求执行时，按现有流程把适合长期使用的内容写进 Wiki 或 Projects，并核对结果。文件较多时会分批处理。
3. **用 `/ask` 查找。** 输入 `/ask` 加上问题，EchoInk 会先检索知识库，有依据时在回答中显示 Sources。最终没有找到依据时会明确说明，再按需使用已有外部资料或模型知识补答。
4. **继续补充。** 新增资料后，可以在“设置 → 知识库管理”里点击“整理新增笔记”。已经处理过的内容不会因为增量整理而整批重做。

`/maintain` 适合整理资料，`/ask` 适合查找和回答。能否写入由会话底部的工作区选项和你的要求决定，快捷指令本身不改变读写权限。普通聊天则用于讨论、写作和推进任务，三种用途可以在同一个侧栏中完成。

## 十个目录分别放什么

| 目录 | 用途 |
| --- | --- |
| `raw` | 原始文件和等待提炼的资料；默认导入内容会保留原路径放在 `raw/imported/` 下 |
| `wiki` | AI 提炼后的长期知识、主题页和索引 |
| `projects` | 按项目组织的资料、背景和阶段性知识 |
| `outputs` | 整理过程记录和生成结果 |
| `inbox` | 暂时还没分类的新笔记 |
| `journal` | 日记、复盘和按时间记录的内容 |
| `work` | 当前正在处理的工作资料 |
| `archive` | 已结束或暂时不用的内容 |
| `templates` | 可以重复使用的笔记模板 |
| `assets` | 图片、PDF 和其他附件，也保存这份指南使用的配图 |

目录是为了减少整理负担，不是要求你每天维护一套复杂规则。拿不准放哪里时，先放 Raw 或 Inbox；需要长期查找的内容再交给 `/maintain`。

## 知识库和长期记忆不是一回事

知识库保存的是你的资料和笔记。长期记忆保存的是 EchoInk 在长期协作中需要记住的事实、偏好、决定和经历。知识库回答“资料里有什么”，记忆帮助 Agent 理解“这件事和你有什么关系、过去怎样决定过”。

五类记忆说明 Agent 需要记住什么；当前自我决定它怎样处理问题和表达。两者互相参考，但记忆不会变成权限，人格也不会改变事实。

开启长期记忆后，EchoInk 只在内容确实具有长期价值时写入一级记忆。回答新问题时，它按相关性召回需要的部分，不会把全部历史一股脑塞进每次对话。开启“离线记忆整理”后，EchoInk 还会在 Obsidian 打开期间定时复盘已有记忆，补充用于联想的二级事实，并局部更新用户画像和 Agent 当前自我。

### 五类长期记忆

| 类型 | 记录什么 |
| --- | --- |
| 事实 | 你确认过、目前仍然有效的客观信息 |
| 观点 | 你当前的看法、判断与稳定偏好 |
| 决定 | 已经形成、后续应该遵守的选择及依据 |
| 进行中 | 正在推进的目标、任务和还没处理完的事项 |
| 经历 | 过去发生过、在相似情况中值得参考的经验 |

系统还会为一级记忆生成少量二级事实，帮助以后通过相关概念想起原记忆。二级事实属于推理参考，不等于你亲口确认过的事实；它与当前证据冲突时，以当前证据为准。

## 哪些内容可以改

- **知识笔记由你控制。** 你可以直接编辑 Vault 中的 Raw、Wiki、Projects 和其他笔记。EchoInk 初始化不会覆盖已有同名文件。
- **一级记忆可以修正、忘记和恢复。** 在“设置 → 复盘 → 记忆修正”里修正内容时，系统会保存一个新版本，并保留旧版本之间的历史关系；忘记操作也可以恢复。
- **二级事实可以编辑或删除。** 它们是系统推导出的联想线索。如果内容不准确，可以在对应一级记忆下调整，不需要把它当成已确认事实。
- **Agent 名称和头像可以随时修改。** 它们属于身份，只改变界面中的称呼和头像，不会重置人格或记忆。

Agent 画像是当前自我的只读公开简介，用户画像则来自有效的用户证据。你可以从一个人格模板开始；重新选择模板只改变基础风格，长期形成的习惯会保留。一次情绪、一次临时要求或当前任务内容不会直接变成长期习惯。

## 人格会影响什么

EchoInk 的当前自我由自然语言写成，包括处理复杂问题的方法、语气、回答结构，以及长期相处中形成的少量代表性习惯。这些内容会影响它怎样与你协作和表达，但不会形成分数、能力值或隐藏等级。

人格不会提高或降低模型能力，也不能改变事实真假、知识库内容、工具权限、安全边界和不可逆操作前的确认要求。名称与头像属于身份，同样不参与这些判断。

接下来可以从一件小事开始：在侧栏里用 `/ask` 问一个你确实想从现有笔记中找到答案的问题。以后有新资料，放进 Raw，再用 `/maintain` 整理即可。
