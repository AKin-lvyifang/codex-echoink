## Format

- SVG: 1024 × 1024 view box, real vector paths, transparent outside the circle, no embedded raster image.
- PNG: 1024 × 1024 RGBA fallback, transparent outside the circle.
- `source/`: untouched generated originals used to build the normalized files.
- `set-preview.png`: visual index only; do not ship it as an avatar.

The SVG files use unique clip-path IDs, so the set can also be inlined on one page without ID collisions.
